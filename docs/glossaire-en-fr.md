# Glossaire anglais → français

La boîte est française, mais deux documents de référence n'existent qu'en
anglais : le livret EN et surtout le feuillet de clarifications, seule source
des règles spéciales de zones. Ce glossaire fixe la correspondance.

**Convention de code** : les identifiants du code sont en anglais, la langue de
l'interface et de la documentation est le français.
